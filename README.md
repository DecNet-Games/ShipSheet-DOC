# ShipSheet-DOC

Documentation site source for **ShipSheet — Content Provenance Ledger** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/ShipSheet-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, The Ledger, Ledger Fields, Backfill & Review Queue, the Red-Flag Scan and its four rules, the Disclosure Draft, the Credits Block, Exports & Files, Settings, the SampleHarbour Sample, What v1 Is Not, FAQ, Troubleshooting, Changelog, Support
- `assets/images/`, `assets/videos/` — the product's real captures and demo media

ShipSheet itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.
